# Beginner Roadmap: Your First Open-Source Contribution

This guide is a learning checklist, not a promise of eligibility for any program.

## 1. Prepare your tools

- Create a GitHub account and enable two-factor authentication.
- Install Git.
- Learn the difference between a repository, commit, branch, issue, and pull request.
- Configure your Git author name and email.

## 2. Learn the workflow

1. Read the contribution guide of a project.
2. Find an issue that is still open and suitable for your skill level.
3. Comment with a concise plan before starting if the project expects this.
4. Fork the repository and create a focused branch.
5. Make and test your change.
6. Commit with a descriptive message.
7. Open a pull request that explains the problem, solution, and tests.

## 3. Choose meaningful work

Good first contributions can include correcting misleading documentation, adding a missing test, reproducing a bug, improving an error message, or fixing a small issue requested by maintainers.

Do not submit meaningless changes just to increase a contribution count. Follow the project's rules and accept that maintainers may request revisions or decline a change.

## 4. Keep an accurate record

For each contribution, record the project, issue or pull-request link, what you changed, why it mattered, test evidence, and outcome. Distinguish clearly between opened, reviewed, merged, and closed pull requests.

## 5. Keep learning

Read review feedback carefully, ask focused questions, and improve the change. Sustainable contributions matter more than a short burst of activity.
