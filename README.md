# OpenSource First Steps

A practical, beginner-friendly collection of resources for people learning how to contribute to open-source software.

> **Project status:** Early-stage learning resource. Contributions, usage, and community impact have not yet been established.

## What this project aims to provide

- A clear introduction to Git and GitHub workflows.
- Checklists for finding and understanding beginner-friendly issues.
- Guidance for writing useful bug reports and pull requests.
- Small, transparent Python examples for learning and practice.
- Contribution guidelines that help newcomers participate respectfully.

## Getting started

1. Read [the beginner roadmap](docs/ROADMAP.md).
2. Review [the contribution guide](CONTRIBUTING.md).
3. Explore the examples in `examples/`.
4. Choose a small improvement and describe the problem it solves before changing files.

## Example: a tiny Python utility

Run the word counter:

```bash
python examples/word_count.py README.md
```

## Project principles

- **Honesty:** never claim usage, downloads, contributors, or impact without evidence.
- **Accessibility:** explain concepts in plain language.
- **Quality:** prefer tested, understandable examples over quantity.
- **Respect:** welcome constructive feedback and follow each project's contribution rules.
